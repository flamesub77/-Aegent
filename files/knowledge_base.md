# 냉연강판 공정원인 분석 지식베이스 (에이전트 참조용)

> 에이전트가 원인 해석 시 참조하는 도메인 지식입니다. 스펙과 표준조건은 이상적 가정값이며 실제 사내 기준으로 교체해야 합니다.

## 1. 공정 흐름

제강(전로 → RH 탈가스) → 연주(슬라브) → 열연(재가열 → 조압연 → 사상압연 → ROT 냉각 → 권취) → 산세 → 냉간압연 → 소둔(CAL 또는 CGL) → 조질압연(SPM) → 검사·출하

- **CAL (연속소둔라인)**: 가열 → 균열 → 서냉/급냉 → 과시효(OA) → 냉각. 비도금 냉연재 생산. 과시효 구간에서 고용 C를 석출시켜 시효성을 낮춤.
- **CGL (연속용융아연도금라인)**: 가열 → 균열 → 냉각 → 아연 도금욕(약 460℃) 침지 → (GA재) 합금화로 재가열(약 500~540℃) → 냉각. 과시효 구간이 없어 고용 C 제어는 성분 설계(IF, BH)에 의존.

## 2. 용어집

| 용어 | 설명 |
|---|---|
| YS (항복강도) | 소성변형이 시작되는 응력. 상·하항복점이 있는 강은 하항복점 또는 0.2% 오프셋 값 사용 |
| TS (인장강도) | 인장시험 최대 하중 / 원단면적 |
| EL (연신율) | 파단 시 표점거리 변화율. 두께·시편 규격에 따라 달라짐 |
| YR (항복비) | YS / TS |
| BH (소부경화량) | 2% 예변형 후 170℃×20분 열처리 시 항복강도 상승량. 외판 내덴트성 확보 |
| YPE (항복점 연신) | 고용 C·N에 의한 불연속 항복. 스트레쳐 스트레인(외관결함) 원인. SPM으로 제거 |
| IF강 | Ti·Nb로 고용 C·N를 완전히 고정한 극저탄소강. 비시효, 고 r값 |
| 유효 Ti (Ti*) | Ti − 3.42N − 1.5S. C 고정에 쓸 수 있는 Ti 양. Ti* ≥ 4C 이면 C 완전 고정 |
| SRT | 슬라브 재가열 온도. 석출원소(Nb, Ti) 재고용 정도 결정 |
| FDT | 사상압연 마무리 온도. Ar3 이상 유지 필요 |
| CT | 권취온도. 석출물 크기·분포와 열연 결정립 크기를 결정하는 핵심 인자 |
| 냉간압하율 | (열연두께 − 냉연두께) / 열연두께. 재결정 구동력, 집합조직(r값) 결정 |
| SS (균열온도) | 소둔 최고 유지온도. 재결정·결정립 성장 정도 결정 |
| OA (과시효) | CAL 과시효 구간 온도. 고용 C 석출 |
| SPM 연신율 | 조질압연 연신율. YPE 제거 및 표면조도·형상 교정 |
| 코일 위치 T/M/B | 선단(Top)/중앙(Middle)/후단(Bottom). 선후단은 ROT 냉각 편차로 CT가 낮아지기 쉬움 |

## 3. 강종별 강화기구와 공정 영향

### 3.1 극저탄 내판 (IF270_IN, Ti 단독 IF)
- 강화기구: 거의 없음(연질). 목표는 높은 연신율과 r값.
- **CT↑** → TiC 조대화, 페라이트 청정화 → YS↓, EL↑
- **SS↑** → 재결정 완료 및 결정립 성장 → YS↓, EL↑
- **압하율↑** → {111} 집합조직 발달 → r값↑, EL↑
- Ti* < 4C 이면 고용 C 잔존 → YS↑, EL↓, 시효 발생

### 3.2 고강도 극저 외판 (IF340_OUT, Ti-Nb 복합 P첨가)
- 강화기구: P, Mn, Si 고용강화. B는 2차 가공취성 방지용.
- **P** 는 강도 기여가 크나(0.01%당 TS 약 7~8MPa) 연신율 저하 동반
- **CT 고온** 시 FeTiP 석출로 고용 P가 소모되어 강도 하락 가능
- **SS 부족(약 800℃ 미만)** 시 부분 미재결정 → YS 급상승, EL 급저하. 외판은 EL·r값 확보가 중요하므로 균열온도 관리가 핵심

### 3.3 BH 외판 (BH340_OUT, Nb 부분안정화)
- 강화기구: 고용강화 + 도장 소부 시 고용 C에 의한 BH
- 고용 C를 수~20ppm 범위로 제어하는 것이 핵심. 너무 적으면 BH 미달, 너무 많으면 상온시효(YPE, 스트레쳐 스트레인)
- **SS↑** → NbC 일부 재고용 → 고용 C↑ → BH↑
- **CT↑** → NbC 석출 증가 → 고용 C↓ → BH↓

### 3.4 저탄 고용강화강 (LC340, LC440R, Ti/Nb 미첨가)
- 강화기구: C, Mn, Si, P 고용강화 + 결정립 크기
- **CT↑** → 시멘타이트·AlN 조대화, 결정립 조대 → YS↓, EL↑
- **SS↑** → 결정립 성장 → YS↓
- **OA 부족** → 고용 C 잔존 → YS↑, 시효 발생 (CAL재)
- **SPM 과다** → 가공경화로 YS↑, EL↓
- 440급은 Mn·P 함량이 높아 성분 편차에 따른 TS·EL 변동이 큼

### 3.5 석출경화강 590C (HSLA590C, Nb 단독계)
- 강화기구: NbC 미세석출 + 결정립 미세화 + 고용강화
- **SRT↓** → Nb 재고용 부족 → 석출 강화량 감소 → 강도↓
- **CT** 가 가장 민감한 인자. 저온(약 550~600℃) 권취 시 미세 석출 극대화. **CT↑** → 석출물 조대화 → YS·TS 크게 하락 (10℃당 YS 약 8MPa 수준)
- **SS↑** → 석출물 조대화·결정립 성장 → YS↓ / **SS 과소** → 미재결정 잔존 → YS↑, EL↓
- **Nb↑** → 강도↑

### 3.6 공통 인자
- **두께**: 박물일수록 동일 규격에서 연신율 측정값이 낮게 나옴. 두께 구간별로 층별해서 비교할 것
- **코일 위치**: 선후단은 CT 저하로 강도↑ 경향. 시험 위치 혼재 여부 확인
- **GA재**: 합금화 재가열 열이력으로 CAL재 대비 YS 소폭 상향, EL 소폭 하향

### 3.7 성형성 지표: r값(소성이방성)과 n값(가공경화지수)
- **r값**: 인장시험 시 폭 방향 변형률 / 두께 방향 변형률. 압연 방향 기준 0°, 45°, 90° 시편으로 r0, r45, r90 측정
- **r̄ (평균 소성이방성)** = (r0 + 2·r45 + r90) / 4. 클수록 두께 감소에 저항 → 딥드로잉성 우수. IF강 핵심 관리 항목
- **Δr (평면이방성)** = (r0 − 2·r45 + r90) / 2. 절댓값이 클수록 드로잉 시 이어링(귀 생김) 발생
- **n값**: 진응력-진변형률 곡선 σ = Kεⁿ 의 지수. 클수록 변형이 고르게 퍼져 장출성·균일 연신 우수
- r̄는 {111} 재결정 집합조직(γ-fiber)이 발달할수록 커진다
  - **냉간압하율↑** → 재결정 구동력·{111} 핵생성 증가 → r̄↑
  - **IF강 CT↑·SS↑** → TiC 조대화로 페라이트 청정화, 결정립 성장 → r̄↑, n↑
  - **고용 C·P·Mn↑** → {111} 발달 방해 → r̄↓, n↓
  - **SS 부족(부분 미재결정)** → 집합조직 미발달 → r̄ 급감, Δr 확대, n↓
- n값은 결정립이 클수록, 고용원소·석출물이 적을수록 커진다. 석출경화강(590급)은 n이 낮다. SPM 과다(예변형)는 n을 낮춘다

## 4. 표면결함 원인

| 결함 | 주요 원인 공정 | 관련 인자 |
|---|---|---|
| 슬리버 / 개재물성 결함 | 제강·연주 | 주조속도 과다, 몰드 탕면 변동, Al2O3 개재물, 외판재에서 민감 |
| 스케일 (압입 스케일) | 열연 | SRT 과다, 디스케일링 압력 부족 |
| 산세 얼룩 / 미산세 | 산세 | 산세 속도 과다, HCl 농도 부족 |
| 파우더링 | CGL(GA) | 합금화 온도 과다 → 도금층 Fe% 과다, Γ상 성장 |
| 드로스 | CGL | 도금욕 온도 변동, 욕 내 Al·Fe 불균형 |

## 5. 원인 분석 표준 절차 (에이전트 따라야 할 순서)

1. **대상 정의**: 강종, 라인, 기간, 두께 구간을 확인하고 데이터를 조회
2. **분포 진단**: YS/TS/EL 히스토그램, 평균·표준편차, 스펙 만족률, Cpk 산출. 비교 기간(또는 전체 기준) 대비 평균 이동이 1σ 이상이면 "상향/하향 분포"로 판정
3. **이탈군 정의**: 스펙 이탈 코일 또는 평균±1σ 밖 코일을 이탈군, 나머지를 정상군으로 구분
4. **인자 비교**: 성분·공정 인자별로 두 군의 평균 차이를 표준편차로 나눈 값(효과크기)과 상관계수를 산출해 순위화
5. **교란 요인 확인**: 두께, 라인(CAL/CGL), 코일 위치, 시편 방향 구성 비율이 두 군에서 다른지 확인
6. **메커니즘 해석**: 위 3장의 강종별 지식으로 인자 변화 방향과 재질 변화 방향이 야금학적으로 일치하는지 검증. 일치하지 않으면 "통계적 연관만 있음"으로 표기
7. **제어 방안 제시**: 목표 조정값, 관리 범위 축소, 설비 점검 항목 등 구체적으로. 데이터 근거가 약하면 추가 확인 필요 사항으로 제시
